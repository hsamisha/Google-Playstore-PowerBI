# Google Play Store Analysis - Power BI Dashboard

## Project Overview

The Google Play Store Analysis is an interactive Business Intelligence project developed using Microsoft Power BI.

The project analyzes Google Play Store application data to understand application distribution, ratings, reviews, installations, application types, pricing, and app-size patterns.

The data is transformed into meaningful KPIs, charts, and interactive visualizations to help users explore application performance and identify important patterns across different categories.

The dashboard is designed to provide a clear and interactive view of the Google Play Store dataset through multiple analytical pages.

## Objective

The main objectives of this project are to:

- Analyze the distribution of applications across different categories.
- Understand application ratings and review patterns.
- Analyze total application installations.
- Compare free and paid applications.
- Analyze application pricing.
- Examine application-size patterns.
- Identify categories with strong application activity.
- Analyze application reviews and user engagement.
- Compare application performance across categories.
- Present the analysis through an interactive Power BI dashboard.
- Generate meaningful insights from the application data.

## Dataset Description

The project uses the Google Play Store application dataset.

The dataset contains information about applications available on the Google Play Store.

### Important Columns

| Column | Description |
|---|---|
| `App` | Application name |
| `Category` | Application category |
| `Rating` | User rating of the application |
| `Reviews` | Number of user reviews |
| `Size` | Application size |
| `Installs` | Approximate number of installations |
| `Type` | Free or Paid application |
| `Price` | Application price |
| `Content Rating` | Intended audience |

## Approach / Methodology

The project was completed through the following stages.

### 1. Data Collection

The Google Play Store application dataset was collected and imported into Power BI.

### 2. Data Loading

The dataset was loaded into Power BI Desktop for transformation, modeling, and visualization.

### 3. Data Cleaning

The data was prepared for analysis by checking and transforming important fields such as:

- Application names
- Categories
- Ratings
- Reviews
- Installations
- Application type
- Price
- Application size
- Content rating

Data inconsistencies and unsuitable values were handled before creating the dashboard.

### 4. Data Transformation

Power Query was used to transform the dataset into an analysis-ready format.

The transformation process included:

- Cleaning columns
- Changing data types
- Preparing numerical fields
- Handling inconsistent values
- Preparing category fields
- Preparing application type fields
- Preparing pricing and size information

### 5. Data Modeling

The Power BI project uses the application data along with supporting category/type information for dashboard analysis.

Dimension tables were used to organize important categorical fields and support dashboard filtering and analysis.

### 6. DAX Measures

DAX measures were created to calculate important dashboard metrics such as:

- Total Apps
- Total Reviews
- Total Installs
- Free Apps
- Paid Apps
- Average Reviews per App
- Average Price

### 7. Dashboard Development

The prepared data and DAX measures were used to create an interactive Power BI dashboard.

The dashboard contains KPI cards, charts, category comparisons, application analysis, pricing analysis, and interactive navigation.

## Analysis & Key Findings

The dashboard focuses on the following major areas.

### Application Category Analysis

Applications are analyzed across different Google Play Store categories to understand the distribution of applications and compare category-level performance.

### Rating Analysis

Application ratings are analyzed to understand user satisfaction patterns and compare average ratings across categories.

### Review Analysis

The number of reviews is used to understand application engagement and compare review activity across applications and categories.

### Installation Analysis

Total installations are analyzed to understand application reach and identify categories and applications with higher installation activity.

### Free vs Paid Analysis

Applications are divided into free and paid types to understand the distribution of application types in the dataset.

### Pricing Analysis

Paid application pricing is analyzed to understand average pricing patterns and differences across application categories.

### App Size Analysis

Application size is analyzed to understand the distribution of application sizes and compare size patterns across categories and application types.

## Recommendations

Based on the analysis areas included in the dashboard, the following recommendations can be considered:

- Monitor application ratings together with review and installation volumes.
- Analyze high-installation categories to understand application popularity.
- Compare free and paid applications when evaluating application-market patterns.
- Monitor user reviews as an indicator of application engagement.
- Evaluate pricing patterns across different application categories.
- Consider application size when developing applications for users with limited storage or network resources.
- Use multiple KPIs rather than relying on a single performance metric.
- Regularly analyze category-level application performance to identify changing market patterns.
